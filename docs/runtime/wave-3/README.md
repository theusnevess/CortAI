# Wave 3 Runtime Audit Artifacts

Wave 3 documentation is grouped by control area so the root `docs/runtime` directory stays navigable.

## Folders

- `gates/` - Wave 3 critical gate and HOLD review artifacts.
- `lane-1/` - Lane 1 documentation reconciliation artifacts.
- `lane-2/boundary/` - Lane 2 boundary classification, evidence, and reconciliation artifacts.
- `lane-3/external-boundary/` - Lane 3 F-003 external-boundary evidence, policy, and guarding artifacts.
- `lane-3/minimal-guard/` - Lane 3 F-003 minimal guard implementation, validation, and test-expectation artifacts.
- `lane-3/final-acceptance/` - Lane 3 final acceptance and fixture-scope decision artifacts.
- `lane-4/account-health/` - Lane 4 F-004 account-health evidence, correction, validation, and acceptance artifacts.
- `decisions/` - Wave 3 cross-lane and post-lane decision artifacts.
- `full-system-reaudit/` - Wave 3 full-system reaudit planning, execution, and review artifacts.
- `exit/` - Wave 3 exit readiness, decision, and review artifacts.

## Notes

Historical artifact bodies may still mention their original creation paths in YAML or prose. The files are now organized by lifecycle stage and lane, while the artifact content remains preserved.
